# 按应用配置普通键位

原型：本地 `prototype/app-keymaps` 分支的 `docs/design/app-keymaps.prototype.html`，提交 `8441e06`。已确认使用 RC003 实物照片，支持点击实体按键位置选择对应动作。

实现约定：

- 保留既有默认键位。应用通过 Bundle ID 匹配，只保存自己覆盖的普通键；没有覆盖的键即时跟随默认。
- 编辑选择与前台应用独立；编辑某个应用不会将它切到前台。
- 自动切换可以关闭，此时所有应用使用默认键位，应用覆盖仍保留。
- 语音键继续使用原有全局配置；按下和松开不因应用切换而更换绑定。
- 切换前台进程、修改配置、停用桥接或释放实体键，会作废对应连发。切回原应用不会恢复旧连发，需松开再按。
- 应用配置通过原生应用选择器添加，重复添加不会清除已有覆盖；移除配置不会修改默认键位。

原生界面：左侧选择编辑范围，中间修改动作，右侧使用仓内实物照片及既有按键热区，并显示当前前台应用和实际生效方案。
